# Coverage_Criteria

# Overview
This repository contains source code for proposed criteria, benchmark used for empirical evaluation, and results of different RQs.

```
├── Coverage                               # Source code of proposed criteria.
    ├── readme.txt                         # Instructions for using proposed criteria.
    └── requirements.txt                   # Dependency and Python virtual environment information.
├── Agents                                 # Contains the agents used in our evaluation.
├── Agent_Results                          # Contains test inputs, coverage results and obtained execution traces. 
├── AgentRx_Results.xlxs                   # Contains the results of AgentRx. 
```

# Coverage Criteria
The source code for proposed criteria are provided in [readme.txt](). Follow the instructions to reproduce the results.

The 12 agents used to evaluate our approach are provided in [Agents](Agents).

# Agent Results
